## Product

SRT Gateway is a web-managed stream routing gateway for broadcast-style SRT, UDP, RTMP, RIST, and HLS workflows. It provides a browser UI/API, stores desired service configuration in Postgres/Redis, runs FFmpeg pipelines on worker containers, publishes telemetry, and supports redundant worker ownership.

## HLS Decisions

HLS output is a local generated output mode, not a normal `destination_url` protocol.

- If no HLS output is enabled, `destination_url` is required.
- If low-res or full HLS output is enabled, `destination_url` may be empty.
- A service may have both normal destination output and HLS output.
- Low-res HLS generates `360p` and `480p` with a short rolling buffer, currently 10 seconds.
- Full HLS generates `720p` and `1080p` with configurable buffer up to 24 hours.
- Full HLS is resource intensive and requires disk-based buffer handling.
- HLS source is supported as `source_protocol: hls` with `source_url`.
- Initial HLS source implementation may ingest and regenerate outputs; smart passthrough/cache is future work.
